# Wise CRM — документация

CRM для бухгалтерской компании (Украина). Приоритеты: простота использования, скорость работы, быстрые действия с клавиатуры и правой кнопкой мыши.

**Фокус итерации 1: привлечение и оформление новых клиентов.** Основной пользователь — менеджер, который ведёт лида от первого контакта до договора. Данные для бухгалтерии на карточке собираются, но процессы бухгалтерии (КЕП, периодическая отчётность, обслуживание) автоматизируются в v1.1. Подробнее — в начале `01-functional-requirements.md`.

Стек: NestJS + Prisma + PostgreSQL 17 + React/Vite + **Mantine 8**. 10 пользователей; система стартует пустой и наполняется новыми лидами.

Размещение: тот же VPS Hostinger, что и сайт (1 vCPU / 4 ГБ / 50 ГБ), поддомен `crm.wisexpert.com.ua` (+ редирект с `/crm`). Уведомления: in-app + Telegram (почта отложена). Бэкап — локальный + снапшоты VPS, без внешнего хранилища.

Статус: требования согласованы (семь волн решений 26.08.2026 — см. `07-open-questions.md`), **MVP реализован и работает в проде** на `crm.wisexpert.com.ua` (первый деплой — 27.08.2026, форма з сайту приймає реальні ліди). Этапы 1–4 закрыты полностью, этап 5 — частично: не хватает внешнего мониторинга `/health` и учений по восстановлению. Оценка на старте — **~6 недель** одним разработчиком: 4,5 на функциональность + 1,5 на тесты. Этапы и критерии готовности — `09-implementation-plan.md`, раздел 4. Гэп-анализ решений — `08-gap-analysis.md`. Работа продолжается сериями небольших фич сверх исходного MVP — `backlog-archived.md` (сделано) и `future-backlog.md` (в очереди).

Открытые вопросы, блокирующие часть решений, — `07-open-questions.md`.
